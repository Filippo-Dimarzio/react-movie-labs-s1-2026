# react-movie-labs


This is my movie app for the React Assignment, I built it with React + Vite and it gets all the movie data from the TMDB API. I started from the lab code and then added extra pages and features on top of it.

### Pages
- **Home**: a list of movies from TMDB's discover endpoint in which you can add movies to your favourites from here.
- **Upcoming**: this shows movies that are coming out soon and with you are able to create Must Watch playlist to allow yourself to come back to them.
- **Popular**: showcases current popular movies, split into pages with a pagination bar at the bottom.
- **Top Rated**: these are highest rated movies on TMDB.
- **Now Playing**: movies that are in cinemas right now.
- **Favourites**: allows you to click the heart and be directed to the favourites page and also you can remove them or write a review from here.
- **Movie Details**: shows the overview, genres, runtime, revenue for one movie, plus its cast and a recommended movies as a way to help you choose.
- **Reviews**: read TMDB reviews for a movie, or write your own with the review form.

### Filtering
Every list page has a filter card on the left where you can:
- search by title
- filter by genre
- filter by **minimum rating** (any, 3+, 4+, 5+, 6+)
